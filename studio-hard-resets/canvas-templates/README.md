# Canvas templates (Hard Resets)

Sanity **Canvas templates** are saved inside Canvas (document menu → **Save as template**), not in this repo. These files are **starters** you paste into Canvas, then save as an org template once **Hard Resets** appears in the studio picker.

| File | Purpose |
|------|---------|
| `hard-reset-issue-template.md` | Issue-shaped paste template (Issue 6 / *arrangedmarriage* example). Same labels as the master content doc. |

Field mapping reference: [`GOOGLE_DOC_MAPPING.md`](../GOOGLE_DOC_MAPPING.md).

Studio not in the Canvas dropdown? See [`docs/HARDRESETS_CANVAS.md`](../../docs/HARDRESETS_CANVAS.md).
