# Canvas templates (The Pickle Report)

Sanity **Canvas templates** are saved inside Canvas (document menu → **Save as template**), not in this repo. These files are **starters** you paste into Canvas, then save as an org template once your studio appears in the picker.

| File | Purpose |
|------|---------|
| `pickle-weekly-issue-template.md` | Issue 19–shaped paste template (same labels as Google Doc export: PUBLISHED ON, PICKLE ECONOMICS TITLE, NIBBLES sources, etc.) |

## Studio not in the Canvas dropdown?

See [`docs/THEPICKLEREPORT_CANVAS.md`](../../docs/THEPICKLEREPORT_CANVAS.md).

Quick checks:

1. [sanity.io/welcome](https://www.sanity.io/welcome) → **Studios & Apps** — is **The Pickle Report** listed? Open it once.
2. [Manage → The Pickle Report → Studios](https://www.sanity.io/manage/project/3owmesrj) — **Show in Dashboard** (not hidden).
3. In Canvas, **Don't see your studio?** → `https://thepicklereport.sanity.studio`
