# Heeb Newsletters — Sanity Studio

Content studio for [heebnewsletters.com](https://heebnewsletters.com) ("From the Vault, by Heeb").

Document type: `vaultIssue`. Project id: `m4gmd2lf`.

## Setup

1. `npm install` then `npm run dev`
2. CORS: `http://localhost:3007`, `https://heebnewsletters.com`, `https://fromthevault.heebnewsletters.com`
3. Set `NEXT_PUBLIC_SANITY_PROJECT_ID=m4gmd2lf` on the Vercel project for `apps/heebnewsletters`
